# Formal experiment protocol and reported scope

The original pre-formal development plan is archived at [experiment_plan_preformal_2026-11-27.md](archive/experiment_plan_preformal_2026-11-27.md). This page describes the completed 24-question comparison and separates it from unfinished diagnostics.

## Fixed material and methods

Before the live run, the project selected every fifth Pack from P01–P20: **P01, P06, P11, P16**. Each Pack has 30 sentence records and one question in each of six task types: Count, Rate, Selection, Comparison, Evidence Explanation, and Insufficient Info. This gives 120 records, 24 frozen questions, and 24 answers per method. The original 120-question candidate pool was not reviewed in full. The selected questions, references, source CSV/Gold, two question-review sheets, adjudication, model, Prompt versions, and strict scoring code are bound by the local frozen release. P01-Q2 remains the Price 0/0→null question; P11-Q6 asks about reviews rated 2 stars or below and has an insufficient-information reference because ratings are absent.

Method A receives raw reviews and the question. Method B uses fixed ABSA extraction and deterministic analysis. Method C uses the same Pack-level extraction as B but selects tools dynamically, verifies output, and permits bounded repair. Gold labels and reference answers are excluded from model requests. The run records requests, responses, shared extraction, answer status, errors, Token usage and latency; interrupted requests are not silently replayed.

The release and run are local-only: `outputs/formal_freeze_release_2026-11-27/release.json`, `outputs/formal_runs/final_v1_unrun/`. The frozen release SHA-256 is `b6052872f25f2ef6de840d14c7f34ef20aa1df62ec0ed2a480f164d776a23dbc`. The complete source-hash chain is in the local final provenance record. [Preflight](formal_preflight.md), [Runner](formal_runner.md), and [Scorer](formal_scoring.md) describe the actual CLI and safety checks; this page is a protocol summary, not a command substitute.

## Scoring and analysis

The independently run strict Gold scorer preserves all 24 slots per method and four per task type. Missing, failed, partial, wrong refusals and incorrect answers stay in their denominators. The scorer produced A 3/24, B 19/24, C 19/24, and the read-only consistency audit matched all 72 judgments. B/C agreed in correctness on all 24 questions, but differed in output content on 19. Shared ABSA request counts and cost are reported once. Estimated cost uses the frozen price inputs and is not a provider invoice.

Twelve anonymized Evidence Explanation answers were subsequently rated for Source Fidelity, Relevance, Sentiment Support, Claim Support, and Completeness. According to the project owner, the owner and two group members discussed and accepted the final judgments. The initial Codex proxy sheet and 11 owner-adjudicated `unclear → yes` changes are retained locally; there are no two separate human reviewer sheets. This is the final group Evidence quality assessment, while the strict question-answer score remains the separate frozen metric. Neither changes the other.

The Pack P01 had one pre-freeze exploratory Method A call on a discarded Food-version Rate question. It is excluded from the frozen experiment, but its exposure is disclosed. A supplementary analysis excluding P01 (18 questions per method) is marked as sensitivity analysis, not a replacement result.
